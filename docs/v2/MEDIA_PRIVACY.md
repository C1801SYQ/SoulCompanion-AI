# 摄像头与麦克风

进入任何页面都不会申请权限。只有在页面可见时，点击“开始陪伴”才申请你选中的摄像头或麦克风权限。可以只选择其中一种；摄像头可以选择前置、后置或已获准后列出的可用摄像头。操作系统是否允许某种设备，由设备和权限设置决定。

采集期间，陪伴页持续显示 Camera / Mic 是否开启、权限状态和采样数量。权限已授予不代表设备正在使用。浏览器或操作系统还会显示自己的设备使用提示。

点击停止、离开陪伴页、应用进入后台、设备断开、浏览器断网或切换情绪数据来源时，会结束采集。回到前台、重新联网或后来允许权限，都不会自动恢复；请再次点击“开始陪伴”。情绪后端未连接不影响主动开始本地预览。如果在权限提示尚未回答时点击停止，后来获得的媒体流也会被立即释放。

本阶段的采集只在设备内运行，没有上传到服务器，也没有情绪推理、语音转写或 AI 回复。界面上的本次情绪保持空白，直到后续服务实际提供结果。DEMO 和 PUBLIC_DEMO_ONLY 只决定情绪数据来源；它们也允许你主动开始本地设备预览。示例情绪不是摄像头或麦克风的推理结果。是否连接情绪服务，不影响本地采集能力。

麦克风输入强度仅表示实际声音幅度，不用于情绪判断。尚无真实测量时不显示假造的零值；平台不能提供该测量时会说明暂不可用。设备名称与标识仅用于当前客户端选择，不发送到服务器或写入持久存储。

默认每秒采样 2 张画面，配置范围为 1–4 张；编码为 JPEG 或 WebP，画面最多 640×480，单帧最多 200 KiB。浏览器音频按实际采样率输出单声道 WAV，默认约 1 秒，配置范围为 500–2000 毫秒，单片最多 128 KiB。微信官方录音接口输出 MP3 分片，其片段时长由接口决定；不会把这些片段伪装为 WAV，也不会从压缩字节伪造音量读数。

客户端不把原始画面、录音、设备名称或权限错误原文写入数据库、浏览器存储、日志或报告。内存只保留完成当前编码所需的有界缓冲；会话界面只保留计数和设备状态。微信接口产生的临时文件会在读取或停止后删除；临时录音文件由平台 API 产生，并不代表完全不接触临时磁盘。文件删除失败必须显示清理失败，不能宣称原始文件已经删除。

后续服务器接入后，仅传输完成推理所需的小画面和音频片段，推理完成后释放原始数据。保存的范围将限于情绪特征、时间戳、派生状态及确有必要的转写内容，并由独立的会话权限保护。训练数据保存如需增加，必须另设明确同意，不能沿用开始陪伴操作。

目前尚未验证 Windows 实体摄像头、Android 手机浏览器、iPhone 浏览器、微信开发者工具或微信真机。微信完整验证需要注册的小程序 AppID；Android APK 构建属于 Phase 08。浏览器自动测试使用 Chromium 虚拟媒体设备，不会调用开发者的真实摄像头或麦克风，其结果不能代替真机结论。

技术依据：[浏览器权限与安全上下文](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[微信录音分片接口](https://docs.taro.zone/docs/apis/media/recorder/RecorderManager)、[Android 应用生命周期](https://capacitorjs.com/docs/apis/app)。
