## 有界真实 UI 验收

复用 **两个既有专用合成账户**，不新增账户，不读取真实家庭记录。私下重置合成密码；密码、令牌、UID 和内容标识只在进程内存与私有 stdin 传递，不记录浏览器 trace、截图、HAR 或凭据日志。

只向第二个合成账户临时授予服务端规范角色 `moderator`，用于本次合成对象的人工审核及举报处理。普通家长无授权仍返回 403；使用 PC03 受保护角色 CLI，不增加授予角色 HTTP。具体人类长期审核员仍未指定，此临时角色不会成为正式运营授权。

最多新增 **1 帖子、1 一级评论、1 举报**。通过官方 CloudBase H5 SDK 与真实页面完成 A 登录/昵称/投稿 pending → 匿名不可见 → B 临时运营审核 → B 浏览/评论 pending/审核 → 点赞收藏 → 举报 → 独立处理举报而不自动隐藏 → A 撤回 → 公开内容消失。

先完成本地 Fake 闭环和工具回归，再执行本计划。异常或不确定写入保留原动作键和不可变合成输入；清理时可同键重放该唯一合成动作以确认落定，再软撤回，防止迟到写入在首次 404 后残留。即使原请求未到达，也最多形成计划内的 1 帖子/1 评论/1 举报，不生成第二逻辑对象。仅清理本次追踪的合成对象，不物理删除家庭记录。finally 中撤回合成帖子/评论、关闭本人关系、恢复测试前合成昵称、撤销临时运营角色、撤销已签发令牌，并读回验证；令牌归属无法核验或清理无法确认时明确 FAIL，不冒充完成。保留软撤回内容、角色/审核审计及幂等/限流/举报记录；这不是删除历史审计。
