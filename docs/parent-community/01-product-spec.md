# PC01 产品规格

日期：2026-10-09。实施范围仅为家长社区可视原型。

## 用户、品牌与入口

对外名称“予怀”，内部 SoulCompanion 技术/资源标识保留。成年家长和监护人使用，服务 0～18 岁儿童家庭。进入社区无诊断标签、购买、订阅、登录或建立儿童档案门槛。产品帮助交流经验和亲子沟通，不提供诊断或已验证 AI 判断。

主入口统一为 **社区 / 育儿知识 / 成长记录 / 我的**。社区为默认首项/首页；旧 Home/Session/Insights/Reports/Settings 路径保留在家庭工具中，原真实数据与 DEMO 行为保持。

主切换采用共享 AppShell 与 Taro.reLaunch；详情/投稿使用 navigateTo/navigateBack；家庭工具从成长/我的进入页面栈，旧工具之间可 redirectTo，避免无限叠加。统一导航定义由一处维护。不配置普通详情为 Tab 页，不引入双重原生/自绘底栏。

## 社区公共数据

`CommunityAgeBand` 为六段 `0-2 / 3-5 / 6-8 / 9-12 / 13-15 / 16-18`，筛选额外提供 `all`。中文标签为“0～2 岁”等，统一常量，不是儿童健康或能力分级。

`CommunityTopic` 为亲子沟通、情绪陪伴、习惯与生活、入园入学、学习与同伴、青春期、家长成长；话题筛选有“全部”。年龄与话题使用 AND，发布时间倒序，无匹配则空状态。

纯展示 DTO 为 CommunityPostPreview / CommunityAuthorPreview；fixture 所有正文、昵称、日期和 ID 均为合成示例。每张卡片和详情持续标注“示例内容”，展示标题、摘要、作者展示名、时间、年龄和话题。没有真实点赞/评论/收藏计数，不伪造热度。

详情使用固定示例 ID 查找，无效 ID 显示不存在和返回入口，不回退到第一篇。正文纯文本，评论说明“功能尚未接入”。列表筛选、滚动位置仅应用内存保存，详情返回恢复；直接打开详情无历史则回社区。

## 投稿预览

字段为标题、正文、主动选择年龄段与话题。标题上限 80 字符，正文上限 2000 字符；trim 后必填，年龄和话题须合法。字数按统一 Unicode code point 口径，输入组件允许保留超限输入并明确提示，避免静默截断。

页面始终显示“功能预览：目前不会发布到社区”。有效输入生成本地预览，允许返回编辑；不调用任何写入 API，不创建云帖、不生成审核状态，不显示发布成功。草稿只保存在当前应用内存，刷新后清空；不存 localStorage/Taro/云端。正文用 Text 展示，不使用 HTML、富文本或自动危险链接。

预览默认作者为合成家长，不读取当前 CloudBase 用户 UID/OpenID、私有儿童昵称、档案 ID 或报告。提醒避免填写孩子姓名、学校、住址和隐私内容。

## 三个辅助入口

- 育儿知识：分龄选择、生活情境分类、真实空状态；无来源文章不冒充专家意见。
- 成长记录：说明未来的家长手动观察，私有记录空状态；提供旧陪伴、洞察、报告入口，明确它们不是新手动记录。
- 我的：展示现有登录状态和显式账户/私有档案入口；公开社区昵称、我的投稿/收藏仅说明未来位置。PC01 不改写认证或提前建立新身份。

## 隐私与生命周期

新公共页面不调用 useResource、CloudRecords 或 CloudAccount，不读家庭档案/报告，不发社区 API 请求、不申请 Camera/Mic。保留全局认证/媒体对象；公共路由必要时暂停私有读取并取消 pending，恢复旧私有页才允许读取，退出/账号变化始终清理旧私有状态。

离开 Session 时保持原 hide/unmount stop，本地释放不等待网络结束。不得修改线上 CloudBase/网关/权限、cloud/api 或 001_metadata.json，数据库和真实审核在 PC03/04 实现。

## 视觉、可访问性与测试

温暖米黄、柔和灰、深暖色文字和克制强调；复用现有 token、Taroify 和可访问组件。桌面清晰侧栏/内容层级，移动四入口底栏、自然换行的筛选和足够大的卡片操作区域。状态有文字，焦点可见，支持字体放大与 reduced motion，不以装饰动画代替信息。

验证 375×812、390×844、430×932、768×1024、1440×900，无横向溢出，触控目标至少 44px；每页有主要导航、main 和清晰一级标题。H5/微信 UI 可不同但业务路由含义一致。

单测先覆盖枚举、年龄/话题/AND/空结果/排序、详情查找和投稿校验；浏览器验证四入口、详情返回状态、输入/预览/编辑、安全文本、示例标识、零私有 API/媒体权限与临时草稿清空。保留旧 E2E、媒体、身份隔离和云后端回归，新增社区测试接入两种 H5 CI 构建。weapp 构建不当作真机 PASS。
