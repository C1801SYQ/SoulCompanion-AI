本地测试、独立审查及限定云写入授权已完成。以下工具默认均为离线计划，不联网、不写云：


工具的实际执行仍要求 `--apply --cloud-write-authorized` 双门槛，并核对本次既有授权范围。每次执行前重新审计，核查原 Phase04 marker。发现无本项目 marker 的同名新集合、陌生 ACL、索引不匹配或 base checksum 不一致时拒绝采用或修复它。[增量 schema 工具](../../scripts/cloud_family_schema.py) 只负责新集合、索引与 marker；[代码部署工具](../../scripts/cloud_family_deploy.py) 只更新已核对的函数代码；[真实验收工具](../../scripts/cloud_family_acceptance.py) 复用两个既有合成账户，不创建新 Auth 用户。
