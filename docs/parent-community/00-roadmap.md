# 予怀家长社区路线

日期：2026-10-09。当前只执行 **PC01**，从已交付 Phase 04 基线继续，不另建项目。

产品面向 0～18 岁儿童家庭，由成年家长/监护人使用。微信小程序优先，H5 用于共享 UI、预览与测试；Android 和实体机器人不属于当前交付。

| 阶段 | 主题 | 当前范围 |
| --- | --- | --- |
| PC01 | 产品重定位与社区可视原型 | 四入口、年龄/话题筛选、示例详情、内存投稿预览、保留家庭工具、自动验证 |
| PC02 | 微信身份与家庭资料 | 规划；真实微信登录/主体权限核实，向后兼容私有家庭年龄资料 |
| PC03 | 社区数据库与审核后端 | 规划；独立增量 schema、纯文本投稿、服务端权限/审核，保护旧 marker |
| PC04 | 真实社区与运营闭环 | 规划；投稿/审核/互动/举报，明确审核人，接通真实 API |
| PC05 | 育儿知识与私有成长记录 | 规划；来源核对、手动观察、私有汇总，不冒充 AI |
| PC06 | 真机与受控体验版交付 | 规划；同一代码真实云端和微信手机验收，不自动正式发布 |

PC01 分支 `pc-01-community-prototype`，父提交 `ce95b555bb1667ec653d05960ba2e47210b8b75d`。只有 PC01 验收通过且后续任务授权后才创建 `pc-02-family-identity`；不自动进入下一段、合并 master、建立社区云资源或升级大模型。
