# 予怀家长社区路线

更新日期：2026-10-11。当前执行 **PC03 社区后端**，沿用已交付 PC01、PC02 和 Phase 01～04 成果，不另建项目。PC03 本地软件验收与真实云验收分开记录。

产品面向 0～18 岁儿童家庭，由成年家长/监护人使用。微信小程序优先，H5 用于共享 UI、预览与测试；Android 和实体机器人不属于当前交付。
